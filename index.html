Benji’s All-exposure HDR simulator (level 1)

Toy forward model of the All-Exposures view from the Jess instrument (Compass software). Each curve is one exposure (1, 2, 4, …, 512 s) plotted as counts / sec (arbitrary units — only the relative shape between curves matters here).

What we actually care about is how much target is in the capillary; counts/sec is the proxy via the chain: more target → (primary in excess) more bound primary → (secondary in excess) more HRP → (with abundant substrate and the camera in its linear range) proportionally more counts/sec.

When substrate runs low, the HRP slows mid-exposure, so long exposures report a lower per-sec than short ones. If only the very long frames drop, no harm done — the short ones still quantify faithfully. But once even the 2 s reads below the 1 s, we’re in burnout: at that point we can’t even trust the 1 s exposure to reflect target amount.

▾Dynamic range across exposures

For each option (Benji’s HDR + the manual single exposures), the colour band shows the status at every concentration on the current substrate setting: green = trustworthy, orange = compromised, red = unreliable. The dashed line marks the current concentration. Note how HDR’s green stripe extends further on both ends than any single exposure — that is the dynamic-range advantage.

▾What this view shows — and what it doesn’t

Everything above — burnout, noise, the per-exposure trade-offs — is about one capillary at one concentration. The status badge flags whether that single reading is faithful: did the substrate hold, is the peak comfortably above noise.

What proves an assay actually quantifies the target is linearity: a serial dilution across the working range must land on a straight line. Without that you don’t know whether a “good” reading at ×1 is still good at ×0.1 or ×10. Spike & recovery, parallelism, etc. round out the validation suite if you need the formal proof.

→ Level 2: standard curve with six samples runs exactly that linearity check — same single-capillary mechanics, but with a serial dilution so you can see the points walk off the line at the edges.
